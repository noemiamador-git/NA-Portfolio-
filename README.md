# Noemi Amador Portfolio

A whimsical personal portfolio for my side work, including photography, YouTube videos, websites, code projects, and creative experiments.

## About

This portfolio is designed to feel like a moody folk-art zine: botanical, cinematic, slightly whimsical, and personal. It includes a featured YouTube video on the opening page, a photography archive, and a code projects section.

## Sections

- Featured YouTube video
- Photography archive
- Code projects
- About / creative direction
- Contact section
